# 음성 작업 인수인계 (Whisper CER 측정)

1주차에 남은 음성 작업을 **음성 파일이 있는 다른 PC**에서 돌리기 위한 안내입니다.
라벨 정리와 학습쌍 만들기는 이미 끝났습니다. 이 PC에서는 Whisper CER만 측정하면 됩니다.

## 무엇을 하는가

사투리 발화 30개를 Whisper(`openai/whisper-large-v3-turbo`)로 받아쓰게 하고 CER(글자 오류율)을 잽니다.
데이터셋 두 개를 따로 잽니다.

| 결과 | 판단 (잠정, 팀에서 확정) |
|---|---|
| CER 0.15 이하 | 데모에 음성 입력 기능을 넣는다 |
| 0.15 ~ 0.30 | 팀 회의에서 결정 |
| 0.30 초과 | 텍스트 입력 데모만 만든다 |

`cer_vs_standard`(표준어 정답 기준 CER)도 함께 나옵니다. 이 값이 `cer_vs_dialect`보다 낮은 문장이 많으면, Whisper가 사투리를 표준어로 고쳐 적는 경향이 있다는 뜻입니다. 결과 분석에 쓸 수 있습니다.

## 준비물

- **NVIDIA GPU, VRAM 4GB 이상 권장.** Whisper turbo는 fp16 기준 약 2GB를 씁니다.
  - GPU가 없어도 CPU로 돌아가지만 느립니다. 두 데이터셋 60문장에 수십 분 걸릴 수 있습니다.
- 디스크: Whisper 모델 약 1.6GB와 음성 zip 크기만큼 필요합니다.
- Python 3.10 이상, git

## 2. 설치

torch는 **GPU(CUDA) 버전**으로 먼저 설치합니다. 그냥 `pip install torch`를 하면 CPU 버전이 깔릴 수 있습니다.
```bash
pip install torch --index-url https://download.pytorch.org/whl/cu128
```

```bash
pip install -r requirements.txt
```

## 3. 데이터 넣기

**zip은 풀지 않고 그대로 넣습니다.** 스크립트가 zip 안을 바로 읽습니다.

```
data/raw/
├── dialect_gs/        014. 한국어 방언 발화(경상도) 라벨
│   ├── Training/(비식별화완료)경상도_학습데이터_1.zip
│   └── Validation/(비식별화완료)경상도_학습데이터_2.zip
├── elder_gs/          139-1. 중·노년층 방언 라벨 (경상도 TL_02, VL_02만, 강원도는 넣지 않음)
│   ├── Training/TL_02. 경상도_01. 1인발화 따라말하기.zip  (_02 질문에답하기, _03 2인발화도)
│   └── Validation/VL_02. 경상도_01. 1인발화 따라말하기.zip  (_02, _03도)
└── audio/             ← 원천데이터(음성) zip 또는 wav를 여기에
```

### 라벨

Kevin이 받아 둔 라벨 zip을 USB 등으로 옮깁니다. 전체 약 6GB입니다.
**음성을 Validation만 받는다면 라벨도 Validation 것만 있으면 됩니다** (014 약 34MB, 중·노년층 약 340MB).

### 음성 (아직 아무도 안 받음)

AI Hub의 같은 데이터셋 페이지에서 **원천데이터**를 받습니다.

- **전부 받을 필요 없습니다.** 30문장만 재면 되므로 각 데이터셋에서 **Validation 원천데이터 zip 하나**면 충분합니다. 다운로드 창에서 크기를 보고 작은 것을 고르세요.
  - 014 방언 발화: `2.Validation` 아래 원천데이터 (경상도)
  - 139-1 중·노년층: `Validation` 아래 원천데이터 중 **경상도(02)** 항목. 예: 2인발화
- 받은 zip을 `data/raw/audio/`에 그대로 넣습니다. 폴더 구조와 상관없이 wav 파일 이름이 라벨 JSON 이름과 같으면 자동으로 짝을 찾습니다.
  - 예: `DKSR20001582.json` ↔ `DKSR20001582.wav`
- AI Hub 데이터는 계정마다 이용 신청 승인이 필요할 수 있습니다. 받은 파일은 팀 안에서만 쓰고 GitHub에 올리지 않습니다.

## 4. 실행

탐색기에서 `scripts\run_whisper.bat`를 더블클릭하거나, 명령창에서 실행합니다.
```bash
scripts\run_whisper.bat
```

자동으로 아래 순서대로 진행됩니다.
1. **환경 점검** (`check_env.py`): 패키지, GPU, 데이터 위치. `[X]`가 나오면 안내대로 고칩니다.
2. **라벨-음성 이름 매칭 확인**: "라벨 JSON N개 중 음성 있는 것 M개"에서 M이 0보다 커야 합니다.
3. **음성 자르기 시험** (모델 없이 5개): 잘린 길이가 (end − start)와 비슷하면 정상입니다.
4. **014 방언 발화 CER** (30문장)
5. **중·노년층 CER** (30문장)

처음 실행할 때 Whisper 모델(약 1.6GB)을 자동으로 받습니다.
한쪽 데이터셋 음성만 넣었다면 다른 쪽은 "후보 0개"로 나오는데, 정상입니다.
문장 수를 바꾸려면 `scripts\run_whisper.bat --n 50`처럼 실행합니다.

## 5. 결과 보내기

`results/` 폴더에 다음 파일이 생깁니다.

| 파일 | 내용 |
|---|---|
| `whisper_cer_summary.csv` | 데이터셋별 평균 CER (사투리 기준, 표준어 기준), 표준어에 더 가깝게 적은 문장 수 |
| `whisper_cer_dialect.csv`, `whisper_cer_elder.csv` | 문장별 정답, Whisper 전사, CER |
| `whisper_log_dialect.txt`, `whisper_log_elder.txt` | 실행 로그 |

GitHub에 올립니다. 음성 파일과 `data/`는 `.gitignore`에 걸려 있어서 올라가지 않습니다.
```bash
git add results/whisper_*
git commit -m "Whisper CER 결과 (경상도 30문장)"
git push
```
git이 익숙하지 않으면 `results` 폴더만 압축해서 카톡으로 Kevin에게 보내도 됩니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `[X] torch가 CPU 버전` | `pip uninstall torch`를 한 뒤 2번의 CUDA 설치 명령을 다시 실행 |
| "음성 있는 것 0개" | 로그의 "음성 이름 예시"와 JSON 이름이 다른 것. 예시 이름을 Kevin에게 알려 주기 |
| "음성 WAV 0개 발견" | `data/raw/audio`에 zip이나 wav가 없음. 원천 음성이 wav가 아닌 형식(pcm 등)이면 Kevin에게 알리기 |
| `CUDA out of memory` | 다른 프로그램을 끄고 다시 실행. 그래도 안 되면 CPU로 실행 (느리지만 됨) |
| 잘린 길이가 0초 또는 이상함 | 라벨 시간과 음성이 안 맞음. `results/whisper_log_*.txt`를 Kevin에게 보내기 |
| 한글이 깨져 보임 | 결과에는 문제없음. CSV는 엑셀에서 열면 정상 (UTF-8 BOM) |
